Note on test conditions Measured on the owner's busy everyday Mac: other apps were open and, for some runs, a large download was running. Answer times may be better on a quiet machine. Correctness is unaffected. One run per question and setting.

Definitions

Exact
The model's own computation: every expert the router picks is read and used.
Skip X
An expert that is not in memory and weighs less than X is skipped instead of read from the SSD. Faster, but changes output.
Terse
The prompt ends with “Answer as briefly as possible. For code, reply with only the code.”
Answer time
Reading the prompt plus generating the answer, in seconds.

1Method

Twenty-four questions in five kinds: eight facts, five sums, four logic puzzles, five small Python functions and two explanations. Each was asked in two styles, normal and terse, under each setting. Normal answers were capped at 128 tokens and decoded greedily.

Grading is automatic. Facts and logic are matched against expected answers, sums by the final number in the answer, and code by running the first code block against unit tests. Because the grader takes the last number and the 128-token cap can cut an answer short, it under-counts long answers. Every answer it marked incorrect was therefore read by hand (Section 3).

2Results

Terse prompts answer every question correctly in every setting and cut the waiting time to about a quarter (Table 1, Figure 1). Generation speed per token is unchanged; the answers are simply shorter. With terse prompts the faster settings save little more time, because reading the prompt now takes most of an answer.

    3Manual review

    Exact and skip 0.3 made no real mistakes: their automatic failures were cut-offs and grader errors. Skip 0.5 produced two genuinely wrong long answers, one degenerating into repetition and one rambling without settling, and it wrote longer answers overall. Skip 0.4 has made no real mistakes in the answers run so far.

    4Discussion

    For everyday use, terse prompts with exact settings give correct answers in about a minute, and skip 0.3 with 12 threads makes that slightly faster with no wrong answers in this bench. Skip 0.5 is fast but risky for long, free-form answers. Twenty-four questions are a smoke test rather than a benchmark: the conclusions hold for this question set and this machine.
