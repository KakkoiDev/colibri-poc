GLM-5.3 on a 32 GB Apple M6: what we changed and what it cost

Exact tuning made GLM about 4× faster on this Mac. Going further means trading answer quality, and 5 tok/s was not reachable here.

How many word-pieces the model writes per second. Generation only; reading the prompt is timed separately.
Expert
GLM is a mixture-of-experts model: each layer sends every token to 8 of 256 small sub-networks. Most experts live on the SSD and must be read in.
Skip threshold
If a needed expert is not in RAM and its weight is below the threshold, skip it instead of reading it. 0 is exact; anything above 0 changes output.

1Why it was slow

Too few CPU threads

The original build had no OpenMP (libomp was not installed), so it ran on one core. Even with libomp, Colibri uses only the M6's 2 "Super" cores out of 12.

Fix: install libomp, rebuild, set OMP_NUM_THREADS=12

CPU-only build

The engine was built without the Apple GPU backend, so the GPU sat idle while the CPU did everything.

Fix: rebuild with METAL=1

No RAM left for an expert cache

Fix: explicit --ram 18 --ctx 1024

9How to run it

Build Colibri with libomp and Metal first. Replace <colibri> and <models> with your own folders.

1 · Build

brew install libomp
make -C <colibri>/c clean glm METAL=1

2a · Exact same output

COLI_METAL=1 PIPE=1 DIRECT=1 COLI_METAL_RESSET=1 COLI_METAL_SPIN=1 OMP_NUM_THREADS=12 \
  <colibri>/c/coli chat --model <models>/glm-5.3 --ram 18 --ctx 1024

2b · Lossy changes output

COLI_METAL=1 PIPE=1 DIRECT=1 COLI_METAL_RESSET=1 COLI_METAL_SPIN=1 OMP_NUM_THREADS=12 \
  DEGRADE_ZERO=1 DEGRADE_TAU=0.5 \
  <colibri>/c/coli chat --model <models>/glm-5.3 --ram 18 --ctx 1024
  • Power use. COLI_METAL_SPIN=1 keeps a GPU keep-alive running the whole time; drop it on battery (about 10-15% slower).
  • Short conversations. --ctx 1024 caps conversation length; it was needed to fit beside other apps.
  • May refuse to start. The engine stops if its projected memory peak exceeds free RAM. Close apps or lower --ram.
  • Threads. OMP_NUM_THREADS=12 overrides Colibri's 2-thread default on the M6. It made no difference for exact runs and +22% for skip 0.5.
  • Don't go above 0.5. At 0.7 answers had grammar errors; at 1.0 the model repeated itself.
