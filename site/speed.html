Speed runs

Every saved engine run of GLM-5.3 on Colibri: all runs, one row each, as measured. The report explains which settings matter and why.

Busy machineThese runs were made on the owner’s everyday Mac with other apps running and free memory changing from run to run. Treat differences under about 10% as noise, compare runs made close together, and expect a quiet machine to be faster.

Table 1. Speed: generated tokens per second after the prompt is read; bold marks the fastest run shown. Prompt read: seconds to read the prompt. Expert hits: share of expert reads served from memory. Memory: resident size of the engine process. Time share: where generation time went, from the engine’s profile; SSD reading dominates almost every run.
